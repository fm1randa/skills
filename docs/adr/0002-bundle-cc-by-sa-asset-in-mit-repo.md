# Bundle Morling's CC BY-SA diagram inside this MIT repo

The `code-review-pyramid` skill bundles `references/code-review-pyramid.svg`, Gunnar Morling's Code Review Pyramid diagram, which is licensed CC BY-SA 4.0. The repo as a whole is MIT.

We bundle it (rather than linking to his hosted copy) so the skill stays self-contained and works offline. This is legal as an *aggregated asset*: the SVG keeps its own CC BY-SA license and carries attribution (a co-located license note, plus credits in the skill and the README), and share-alike applies to adaptations of the diagram, not to the MIT-licensed code around it. The alternative — linking out — was rejected because it makes the skill break if the URL moves. A future reader who sees a CC BY-SA file in an MIT repo should read this rather than "fix" it.
